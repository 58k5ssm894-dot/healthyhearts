# healthyhearts

Educational clinical decision tools for ordering clinicians.

## Echo Stewardship (default tool)

Interactive gate for **resting transthoracic echocardiography (TTE)** when echo is a scarce resource:

- **Green-light** resting TTE for structure/function indications aligned with ACC/AHA Appropriate Use Criteria
- **Divert** pure ischemia workups to treadmill exercise ECG, stress imaging, or CCTA when those fit better
- **Stop** rarely appropriate screening/surveillance orders

Sources (simplified educational map, not a complete AUC catalog): 2011 Multisociety AUC for Echocardiography; 2019 Multimodality AUC (nonvalvular); 2021 AHA/ACC Chest Pain Guideline; 2023 Multimodality AUC for Chronic Coronary Disease.

Open `index.html` in a browser. For qualified professionals only — supplement to clinical judgment.
